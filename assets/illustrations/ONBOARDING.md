# Brandak onboarding artwork

Four dedicated transparent hero illustrations, generated with the built-in image_gen tool. Exact prompts: onboarding-prompts.json.

The onboarding slides reference these assets through the shared Illustration component. They use the existing responsive square art area, contain sizing and slide animations.
