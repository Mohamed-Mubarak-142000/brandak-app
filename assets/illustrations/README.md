# Brandak illustrations

15 square PNG assets with transparent backgrounds, generated with the built-in image_gen tool. The complete prompts are in [prompts.json](./prompts.json).

The shared Illustration component uses contain sizing at the existing screen dimensions. Artwork is bundled locally and does not need an image server.

| Asset | Placement |
| --- | --- |
| brands.png | Marketplace introduction: showrooms, warehouses, shops and brands |
| cart.png | Shopping and multi-store ordering introduction |
| trust.png | Cash on delivery introduction and payment information |
| store.png | Seller introduction and merchant discovery |
| bag.png | Empty cart and sign-in shopping prompt |
| heart.png | Empty wishlist |
| search.png | Empty search results and product listings |
| box.png | Empty orders and seller product listings |
| empty.png | Generic empty lists and reviews |
| pending.png | Application and payment review |
| success.png | Successful order and approved payment |
| error.png | Recoverable data errors |
| offline.png | Network unavailable |
| bell.png | Empty notifications |
| address.png | Empty delivery addresses |
