# فاترينة 1.1.0 — ملاحظات النسخة

انسخ النص اللي تحت في خانة **Release notes** (العربي) في Google Play Console:

```
<ar>
• أقسام أوضح: كل قسم رئيسي فيه أقسام فرعية (رجالي › تيشيرتات، أجهزة › ثلاجات...)
• فلترة بالمواصفات: الماركة، الحالة، الضمان وغيرهم
• صفحة المنتج فيها جدول مواصفات ودليل مقاسات
• لأصحاب المتاجر: إضافة منتج أسهل، تختار المقاسات والألوان من قوائم جاهزة وتكتب كمية كل اختيار في جدول
• المخازن: جملة وقطاعي، والبيع بالكرتونة أو الدستة
• تحسينات في السلة والبحث والأداء
</ar>
```

## خطوات الرفع

1. استنى بيلد Expo يخلص (لينك الـ AAB بيظهر في expo.dev › Builds).
2. Google Play Console › فاترينة › **Production** (أو نفس الـ Track اللي عليه النسخة الحالية) › **Create new release**.
3. ارفع ملف الـ `.aab`، والصق ملاحظات النسخة اللي فوق، وبعدين **Review release › Start rollout**.
4. التحديث بيوصل للمستخدمين بعد مراجعة جوجل (غالباً من ساعات لـ يومين).
